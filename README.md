# Barcode / QR Scanner Demo

A browser-based barcode and QR code scanner demo built with HTML, JavaScript, and `html5-qrcode`.

## Demo

https://yourname.github.io/barcode-qr-scanner-demo/

## Features

- Scan QR codes and barcodes with the device camera
- Decode from uploaded images
- Mobile-friendly interface
- PWA support with manifest and service worker
- Scan history and quick actions

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- html5-qrcode
- Service Worker
- Web App Manifest

## Files

- `index.html`
- `barcode-scanner-manifest.webmanifest`
- `barcode-scanner-sw.js`
- `barcode-scanner-icon-192.png`
- `barcode-scanner-icon-512.png`
- `html5-qrcode.min.js`

## Notes

- Camera access requires HTTPS or localhost.
- GitHub Pages supports HTTPS, so camera scanning should work on supported browsers.
